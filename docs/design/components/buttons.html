Design Rules (Locked)

  • Transition: All buttons use 200ms ease (ALWAYS)
  • Button Pairing: Primary (salmon) ALWAYS comes before secondary (outline)
  • Mobile: Buttons stack vertically and go full width
  • Focus: 2px salmon outline with 2px offset for keyboard navigation
  • Active: 1px translateY down on click
  • Disabled: Gray background/border with 60% opacity
  • Border Accounting: Secondary buttons use 2px less padding to account for border

Icon Only (Favicon, Social)

  • Use for: Favicons, app icons, social media thumbnails
  • Sizes: 16px, 32px, 48px, 192px, 512px
  • Always include alt text when used alone
  • Logo only (no text) when space is very limited

General Guidelines

  • File location: podcast/yudame-logo.png
  • Format: PNG with transparency
  • Color: Yellow/gold "A" shape
  • Always pair with "Yudame Research" text except for favicons/icons
  • Text font: Always Playfair Display (serif), weight 600
  • No hover effect on logo and text in navigation
  • Maintain aspect ratio when scaling
  • Minimum clear space: 8px around all sides
  • Don't modify or add effects to the logo image

## Key Design Elements to Emphasize

For all prompts, the UI generator should prioritize:

1. **Color Palette**
   - Base: White (#FFFFFF) and cream (#F5F1E8)
   - Primary text: Black (#000000)
   - Accent: Muted salmon pink (#E8B4A8)
   - Supporting: Light grays for borders/dividers

2. **Typography**
   - Serif for headlines and emphasis
   - Sans-serif for UI and body text
   - Monospace for technical/data elements
   - Generous line spacing (1.5-1.6)

3. **Textures & Details**
   - Subtle paper grain on cream backgrounds
   - Graph paper grid patterns (very subtle)
   - Hand-drawn elements (dots, lines, underlines)
   - Minimal shadows (soft, barely visible)

4. **Layout**
   - Generous whitespace and margins
   - Clear hierarchy through scale, not color
   - 8px grid system
   - Centered content columns for reading

5. **Interactive Elements**
   - Minimal rounded corners (4-6px)
   - Salmon accent on hover states
   - Clean borders (1px solid or 2px dashed)
   - Subtle transitions
